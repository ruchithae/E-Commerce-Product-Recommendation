# 🛒 E-Commerce Product Recommendation System

## 📌 Project Overview

This project is an E-Commerce Product Recommendation System that recommends products to users based on their previous ratings.

The system uses collaborative filtering and cosine similarity to identify products that users may prefer.

## 🚀 Live Demo

[Click here to open the live app]
https://ruchithae-e-commerce-product-recommendation-app-lje9tn.streamlit.app/

## 🎯 Objectives

- Recommend relevant products to users
- Predict ratings for recommended products
- Calculate recommendation performance
- Provide an interactive web application

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Streamlit

## 📊 Dataset

The dataset contains:

- 8 Users
- 6 Products
- 24 Ratings

## 🤖 Recommendation Method

The system uses:

1. User-item rating data
2. Product similarity
3. Cosine similarity
4. Collaborative filtering
5. Predicted ratings

## 📈 Model Evaluation

The recommendation system achieved:

| Metric | Score |
|---|---:|
| Precision@3 | 0.2083 |
| Recall@3 | 0.6250 |
| NDCG@3 | 0.5000 |

## 💻 Application Features

- Select a user
- Choose number of recommendations
- Get personalized product recommendations
- Display predicted ratings
- View model evaluation metrics
- View dataset information
- View user ratings
